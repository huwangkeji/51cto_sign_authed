# 51CTO博客青龙签到脚本

纯 HTTP 请求实现，无需 Puppeteer/Chromium，零外部依赖。

## 一、部署步骤

### 1. 上传脚本

将 `51cto_sign.js` 上传到青龙面板脚本目录。

### 2. 配置环境变量

青龙面板 → **环境变量** → 添加：

| 名称 | 值 | 备注 |
|------|-----|------|
| `ICTO_BLOG_ACCOUNTS` | `13931707523@Shidun110` | 账号@密码，多账号用 `&` 分隔 |

多账号示例：`13931707523@Shidun110&13800138000@Password2`

### 3. 添加定时任务

青龙面板 → **定时任务** → 创建：

| 字段 | 值 |
|------|-----|
| 名称 | 51CTO博客签到 |
| 命令 | `task 51cto_sign.js` |
| 定时规则 | `0 9 * * *` |

## 二、技术原理

1. **登录**: POST `home.51cto.com/index`（CSRF + 账号密码）
2. **获取 Token**: 访问 `blog.51cto.com/user/sign`，从 `__NUXT__` 提取 API token
3. **签名算法**: `sign = md5(md5(urlPath) + md5(keys + md5(token) + md5(timestamp)))`
4. **签到**: POST `api-blog.51cto.com/sign/run`（带签名参数）

## 三、常见问题

### Q1: 签到结果"签到请求成功"而非"签到成功"

正常现象。今日已签到时 API 返回 `alert:0`，脚本统一报"签到请求成功"。

### Q2: 登录Cookie同步失败

- 确认账号密码正确
- 检查是否触发验证码（频繁登录可能触发）
- 尝试更换签到时间

### Q3: 定时任务超时

脚本执行约 5 秒，无需调整超时时间。

## 四、安全提示

- 密码仅存储在青龙环境变量中，脚本不记录密码
- 建议定期修改密码
